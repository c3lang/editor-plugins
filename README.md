# Editor Plugins
This repository contains editor plugins for syntax colouring in various
editors.

Currently available are:
- [VS Code](https://github.com/c3lang/vscode-c3)
- [Emacs 29+](https://github.com/c3lang/c3-ts-mode)
- [Emacs <= 28](https://github.com/c3lang/editor-plugins/tree/main/emacs-simple)
- [NeoVim](https://github.com/ManuLinares/nvim-c3)
- [Vim](https://github.com/c3lang/editor-plugins/tree/main/vim)
- [Sublime Text](https://github.com/c3lang/editor-plugins/tree/main/sublime-text)
- [Nano](https://github.com/c3lang/editor-plugins/tree/main/nano)
- [Notepad++](https://github.com/c3lang/editor-plugins/tree/main/notepad++)
- [Kakoune](https://github.com/c3lang/editor-plugins/tree/main/kakoune)
- [Kate](https://github.com/c3lang/editor-plugins/tree/main/kate)
- [Lite-xl](https://github.com/c3lang/editor-plugins/tree/main/lite-xl)
- [Micro](https://github.com/c3lang/editor-plugins/tree/main/micro)
- [DTE](https://github.com/c3lang/editor-plugins/tree/main/dte)
- [Iro](https://github.com/c3lang/editor-plugins/tree/main/iro)
- [Zed](https://github.com/AineeJames/c3-zed)
- [Pragtical](https://github.com/0riginaln0/pragtical-c3)

Please note that since the language is still undergoing revisions, these may or may not be completely
current.
